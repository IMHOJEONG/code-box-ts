## 상태 관리 

### 1. 상태? 

- 리액트 애플리케이션의 상태 = 렌더링에 영향을 줄 수 있는 동적인 데이터 값 

    - 상태 - 시간이 지나면서 변할 수 있는 동적인 데이터 & 값이 변경될 때마다 컴포넌트의 렌더링 결과물에 영향을 줌 

    - 지역, 전역, 서버 상태로 분류 가능 

    - 성능 및 상태 복잡성 문제 존재 - 외부 상태 라이브러리를 주로 함께 활용 

### 지역 상태 = Local State
 
- 컴포넌트 내부에서 사용되는 상태 

- useState, useReducer와 같은 훅을 사용 

### 전역 상태 - Global State 

- 앱 전체에서 공유하는 상태, 여러 개의 컴포넌트가 전역 상태를 사용할 수 있으며, 상태가 변경되면 컴포넌트들도 업데이트 됨 

- Prop Drilling 문제를 피하고자, 지역 상태를 해당 컴포넌트들 사이의 전역 상태로 공유도 가능 

### 서버 상태 - Server State 

- 사용자 정보, 글 목록 등 외부 서버에 저장해야 하는 상태들을 의미 

- UI 상태와 결합해 관리하게 되며, 로딩 여부나 에러 상태 등을 포함함 

- 지역 또는 전역 상태와 동일한 방법으로 관리되며 react-query, swr와 같은 외부 라이브러리를 사용하여 관리하기도 함
