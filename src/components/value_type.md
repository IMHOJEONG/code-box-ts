### README 

- JS 문법의 여러 키워드가 TS에서 값 또는 타입으로 해석되는 방식을 정리

| 키워드 | 값 | 타입 |
|---|---|---|
| class             | Y | Y | 
| const, let, var   | Y | N | 
| enum              | Y | Y |
| function          | Y | N |
| interface         | N | Y |
| type              | N | Y |
| namespace         | Y | N |
